# 轻知闯关 MVP 运行与验收

小程序使用 Taro 4.3.3 的 React + TypeScript 项目模板。PostgreSQL 16 运行在 Docker Compose，FastAPI、AI 工作进程和 Taro 构建运行在宿主机。

## 本机启动

准备 Docker Compose、Node.js 20.18 或更高版本、npm 和 uv。后端的 `.python-version` 指定 Python 3.12。

在仓库根目录启动数据库，在后端目录建立本机配置并执行迁移。

```bash
docker compose up -d --wait postgres
cd backend
cp -n .env.example .env
uv sync --locked
uv run --locked alembic upgrade head
uv run --locked uvicorn app.main:app --host 127.0.0.1 --port 8000
```

数据库端口为 `127.0.0.1:55432`，API 文档在 `http://127.0.0.1:8000/docs`。开发配置的 `APP_ENV=development` 提供本地测试会话。

将实际的 `DEEPSEEK_API_KEY` 写入 `backend/.env`，再从另一个终端启动工作进程。默认模型为 `deepseek-flash`。工作进程处理出题、证据核验与通关总结。每日出题限额默认为每用户 8 组、全局 500 组。每日总结模型调用限额默认为每用户 24 次、全局 1,200 次。两组限额可通过 [后端配置](../backend/app/config.py) 对应的环境变量调整。

```bash
cd backend
uv run --locked python -m app.worker
```

从仓库根目录构建本地小程序。微信开发者工具可导入 `frontend`，项目配置将运行目录指向 `frontend/dist`。

```bash
cd frontend
npm ci
QINGZHI_DEV_AUTH=1 npm run build:weapp:dev
```

默认开发接口为 `http://127.0.0.1:8000`。在本机微信开发者工具预览时，允许项目请求这个本地开发地址。若只想练习固定的 20 道题，可附加 `QINGZHI_DEV_FIXED_QUIZ=1`，首页会显示固定题组入口，答题和历史可在没有模型密钥时运行。AI 出题和总结需要工作进程。

正式构建使用 `TARO_APP_ID` 和配置进微信小程序的 HTTPS API 域名，再用微信开发者工具导入生成的 `frontend/dist`。后端使用 `APP_ENV=production`，同时配置同一小程序的 `WECHAT_APP_ID`、`WECHAT_APP_SECRET` 和模型密钥。

```bash
cd frontend
TARO_APP_ID=wx-your-app-id QINGZHI_API_BASE_URL=https://api.example.com npm run build:weapp
```

## 验收命令

从仓库根目录运行以下命令。后端测试在 Compose 创建的 `qingzhi_test` 库中逐测试迁移临时 schema。真实 DeepSeek 的完整链路脚本使用开发会话和本地 HTTP API。

```bash
(cd backend && uv run --locked pytest --cov=app --cov-branch --cov-report=term-missing)
(cd backend && uv run --locked alembic check)
(cd backend && uv run --locked ruff check . && uv run --locked ruff format --check .)
npm --prefix frontend test
npm --prefix frontend run typecheck
(cd backend && uv run --locked python scripts/smoke.py)
```

如有接口变更，从当前后端导出契约并重新生成小程序类型。

```bash
(cd backend && uv run --locked python -c 'import json; from app.config import Settings; from app.main import create_app; print(json.dumps(create_app(Settings(app_env="development")).openapi(), ensure_ascii=False))') > /tmp/qingzhi-openapi.json
npm --prefix frontend run types:api -- /tmp/qingzhi-openapi.json
```

本轮 97 项后端测试和 8 项前端测试通过。后端应用代码合并行与分支的覆盖率为 94%。微信小程序开发与生产构建均通过。浏览器组件预览用于对照原型与跑通界面，原生微信开发者工具的界面和真实微信登录留待联调。

两个主题均跑通真实 DeepSeek 起题、题组核验、逐题讲解与证据、20 题结算、AI 总结和历史回看。「四季成因」示例答对 13 题，「月相变化」示例答对 6 题。
